Dapur Kilat — game memasak 2D: pesanan masuk di papan, klik bahan di counter untuk merakit hidangan Indonesia (Nasi Goreng, Mie Goreng, Sate Ayam, Gado-Gado, Bakso, Ayam Geprek), masak di wajan, sajikan sebelum kesabaran pelanggan habis. Kombo beruntun, level naik, shift 2½ menit.

## Run it

```sh
node serve.ts
```

Lalu buka http://localhost:8080 — klik bahan (atau tombol 1–7), Spasi untuk masak, Enter untuk sajikan, Del untuk buang piring, R untuk mulai lagi. Game berjalan offline dari file statis di `game/`, tanpa network.
